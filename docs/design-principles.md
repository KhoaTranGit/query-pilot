# Definition of distinctive value

QueryPilot is not claiming to invent text-to-SQL, semantic layers, RAG, or agentic BI. The portfolio differentiation is the *combined workflow* that adapts to an unknown CSV bundle, flags ambiguous semantics, enables human-approved joins, conducts bounded multi-step exploration, and supplies a verifiable evidence record for every finding.

## Portfolio demonstration contract

Show two unrelated domains with no source-code edits; upload unknown column names; catch a fanout trap; ask a question requiring clarification; run a multi-query investigation; reveal SQL, lineage and exact arithmetic; refuse a missing metric; compare baseline accuracy and latency. Public presentation must distinguish demo fiction from verified findings.


## Approved visual design direction (2026-11-14)

The refreshed `ui.png` supersedes the denser earlier mockup. Treat calm clarity and progressive disclosure as functional design constraints, not optional styling. Keep the soft tinted background, generous spacing, friendly onboarding illustration, prominent natural-language query box, and one chart + one evidence card as the default analysis composition. Move relationship editing, technical diagnostics, SQL, and extended charts into context-aware views/drawers. The dashboard must remain approachable to nontechnical stakeholders while preserving full auditability for analysts. For detailed requirements and acceptance checks see `docs/ui-spec.md`.
